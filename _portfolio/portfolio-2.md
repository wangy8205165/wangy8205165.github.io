* Built a lightweight, custom multi-agent simulator inspired by **MineDojo** and **Voyager**, featuring a structured grid environment that runs efficiently on CPU.
* Implemented a matrix-based map representation with agent and resource encoding for efficient state tracking.
* Designed structured input/output formats to streamline communication between large language models (LLMs) and the environment.
* Designed a decentralized architecture enabling agents to communicate and coordinate directly with one another. 
* Evaluated movement-based versus target-based planning strategies.
* Benchmarked model performance across GPT-4o, GPT-o1, Llama, and DeepSeek-V3.
* Enhanced model effectiveness through prompt engineering and context management techniques.
* Improved the model performance by adding knowledge memory features. 
* Made many interesting observations.
